# Local user-feedback study: prepared protocol, no results collected

This protocol supports the next evaluation step for Filmory running locally. It is not a record of completed participants, and it must not be cited as measured effectiveness.

## Procedure

1. Ask volunteer participants to supply a short sequence of movie titles they have seen and liked. Use participant codes rather than names in recorded feedback.
2. Generate the legacy neighbor list and the frozen sequence/neighbor list from the same history. Exclude the same seen titles and use the same catalogue for both conditions.
3. Show each list of ten with the same title, synopsis and artwork presentation. Label them A and B without revealing the method. Randomize which method is A and which list is shown first.
4. For every displayed movie, record whether it was already seen and whether the participant would watch it, on a 1--5 scale. Ask which list they prefer overall and why.
5. Keep both lists and all feedback, including unfavorable results. Do not alter ranking weights using feedback that will later be presented as the final test.

An initial local feasibility study can identify usability problems. A larger participant study and its sample-size plan should be agreed with the advisor before making general effectiveness claims.

## Reporting

Report participant count, recruitment method, missing responses, display order, and the exact rating question. Compare conditions within each participant and resample participants rather than treating their ten movie ratings as independent people. Keep willingness to watch separate from observed real viewing. No streaming playback or completion percentage should be inferred from Filmory's simulated Play button.
